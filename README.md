# Mittul Agarwal — Data Specialist Portfolio

A clean, professional portfolio website showcasing data analytics, Power BI dashboards, Python tools, and hardware projects. Built as a single-page responsive site.

## Overview

Designed to present work in a structured, category-based format — Data Analysis & BI, Python Tools, Hardware & Embedded — making it easy for recruiters and clients to find relevant projects.

## Built With

- HTML5 · CSS3 (vanilla, no frameworks)
- JavaScript (smooth scroll, responsive layout)
- Inter + JetBrains Mono (Google Fonts)
- Deployed via GitHub Pages

## Sections

- **Hero** — Role, tagline, project count stats
- **Projects** — 3 categories, 8 repos with tech tags + GitHub links
- **About** — Bio, education timeline, skill bars (Python, Power BI, SQL, Excel)
- **Contact** — Email, LinkedIn, GitHub, WhatsApp
